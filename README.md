# Boost2Business · האתר והעסק, מהליד ועד התמיכה

הפרויקט הזה מכיל את כל מה שצריך כדי שסשן חדש של Claude Code ימשיך לבנות את העסק בלי להסביר הכל מחדש:
- **האתר המעודכן v6.1:** קוד מקור, חבילה ל-Netlify וכלי בדיקה. העיצוב מאושר ונעול.
- **התוכנית לעסק:** איך ליד מוואטסאפ הופך ללקוח משלם ומלווה. ניהול לידים, שיחת אפיון, הצעת מחיר, תשלום, אפיון מלא, יישום, תשתיות, עלייה לאוויר ותמיכה.
- **טיוטות מוכנות בעברית:** תשובות לוואטסאפ, תסריט שיחה, הצעת מחיר, אפיון, צ׳קליסט עלייה לאוויר ותמיכה.
- **ההחלטות שמחכות לך,** כל אחת עם ברירת מחדל.

## איך פותחים את זה כפרויקט ב-GitHub (חד־פעמי, כ-5 דקות)
1. **יוצרים ריפו חדש** (מתחברים בעצמך): https://github.com/new
   - Repository name: `boost2business`, או שם אחר שתבחרי.
   - **Private**.
   - **לא** מסמנים README, .gitignore או license. הריפו צריך להיות ריק.
   - לוחצים **Create repository**.
2. **פותחים סשן חדש של Claude Code:** https://claude.ai/code
   - בוחרים את הריפו שיצרת. אם הוא לא מופיע, צריך לאשר ל-Claude גישה ל-GitHub. האישור הוא שלך.
3. **מדביקים את הפרומפט הראשון** שלמטה, כמו שהוא.
4. **אופציונלי:** מחברים את Netlify לריפו, כך שכל שינוי באתר יעלה לבד: Netlify ← boost2business ← Project configuration ← Build & deploy ← Link repository. עד אז, ממשיכים להעלות zip ב-Deploys.

```
זה פרויקט Boost2Business. הריפו ריק. קודם תביא את החבילה:
1. Artifact tool, action "read", url https://claude.ai/artifact/U1GnmfdakHBweKp9jGNEmu, path "kit/MANIFEST.txt". זו רשימה של כל הקבצים.
2. קריאה אחת עם paths = כל שורה במניפסט עם התחילית "kit/".
3. תעתיק את תיקיית kit לשורש הריפו, תעשה commit עם ההודעה "Boost2Business handover kit (v6.1 site + ops)" ותעשה push.
אם קובץ נכשל, תנסה שוב פעם אחת. אם הוא עדיין נכשל, תגיד לי איזה.
אחר כך תקרא את CLAUDE.md, docs/HANDOVER.md, docs/PIPELINE.md, docs/DECISIONS.md ו-docs/TASK.md, ותתחיל לפי docs/TASK.md.
שלח לי קודם הודעה קצרה בעברית עם מה שתבנה בשלב 1 ועם ההחלטות D1–D4 (עם ברירות המחדל), ואז תבנה בלי לחכות.
אל תפרסם מחירים, תנאי תשלום או ערבות בלי מספרים שאני כתבתי. אל תיצור חשבונות ואל תבקש סיסמאות.
```

## להעלות את האתר לאוויר (Netlify)
1. מתחברים: https://app.netlify.com/login
2. נכנסים ישר לעמוד ההעלאה: https://app.netlify.com/projects/boost2business/deploys
3. בתחתית העמוד גוררים את `boost2business-v6-netlify.zip`, או לוחצים על browse to upload. לא צריך לחלץ את הקובץ.
4. מחכים ל-**Published** בירוק, ובודקים בחלון גלישה בסתר: https://boost2business.netlify.app

> לא משתמשים ב-Netlify Drop. הוא יוצר אתר חדש עם שם אקראי שמבקש התחברות.
