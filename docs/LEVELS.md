# איך עובדים ברמה מסוימת (וחוסכים טוקנים)

Claude Code טוען אוטומטית את `CLAUDE.md` של התיקייה שבה פותחים את הסשן **ושל כל התיקיות שמעליה**. לכן:

| רוצה לעבוד על | פותחים סשן בתיקייה | נטען |
|---|---|---|
| האתר | `site/` | שורש (דק) + `site/CLAUDE.md` |
| צנרת לידים / Duet | `duet/` | שורש (דק) + `duet/CLAUDE.md` |
| סוכן Aggi | `Aggi - new customer agent/` | שורש (דק) + `Aggi/CLAUDE.md` |
| כמה תחומים יחד | השורש | רק השורש; את שאר הרמות קוראים לפי צורך |

כללים לשמירה על המבנה:
- **רמה עליונה נשארת קצרה** (כ-5KB). מה שרלוונטי לתחום אחד עובר לרמה שלו.
- **רמה תחתונה לא מעתיקה את העליונה.** היא מפנה אליה.
- **מסמך גדול לא נטען אוטומטית:** שמים אותו ב-`docs/` ומפנים אליו משורה אחת.
- רמה חדשה (למשל `flows/` ב-Aggi) נפתחת רק כשיש מה לכתוב בה, עם `CLAUDE.md` של עד ~1KB.
