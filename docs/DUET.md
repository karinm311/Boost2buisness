**What Claude Duet is** (https://claude.com/resources/articles/claude-duet, read 6 Nov 2026):
- A proactive agent app: a morning brief, checks every few hours, and background work on its own VM.
- It **inherits the Claude account's skills, memory and connectors** (Gmail, Calendar, Drive, HubSpot, Stripe…).
- It asks before it sends, pays, signs or deletes.
- It is a research preview behind a waitlist, US Pro/Max first.
- The article says nothing about recordings.

So the team is built as **Claude skills**. They work today in claude.ai and in Claude Code (this repo mirrors them to `.claude/skills/`), and in Duet once she has access.

## Client folder
`<root>/C-0001 <name>/` holds:
- `client.json`;
- `timeline.jsonl` (append-only);
- `inbox/`, `calls/`, `outbox/` (drafts: .md + .eml), `docs/`;
- `HISTORY.md` (generated).

The root comes from `--root`, else `$B2B_CLIENTS_DIR`, else `./clients`. The `clients/` folder is gitignored. Karin keeps the real root on her computer for now (her answer, 27 Oct). Drive comes later.

## Rules baked in
- Drafts only: Gmail drafts when the connector is there, else `.eml` files. Karin approves (`approve`) and sends; then `sent --type <event>` moves the pipeline.
- `call_transcript` / `call_recording` refuse to log without recorded consent (`--consent-given` or `consents.recording=yes`). Without consent, use `call_notes`.
- Claude doesn't transcribe audio: the transcript comes from her recorder or meeting tool. Local Whisper is not possible in the cloud sandbox (HuggingFace blocked).
- Payment requests wait for D5–D9. No prices, terms or guarantees unless Karin typed them.
- Value propositions come only from `value-props.json`, which is site copy plus the fact whitelist. It has no numbers.

## Change the process
1. Edit `duet/rules.json`, a skill, or a template in `duet/shared/`.
2. Run `python3 -m unittest discover duet/tests`.
3. Run `python3 tools/build_duet.py`.
4. Give Karin the changed zips to re-upload.

## Claude Code alternative (until Duet is on Karin's plan): `/duet` + sub-agents
Karin, 6 Nov 2026: "duet עדיין לא זמין פה המנוי שלי. עד אז תגדיר אלטרנטיבה ל-agent orchestration and sub agents".

**How it works:**
- `/duet <input>` (`duet/commands/duet.md` → `.claude/commands/`) is the orchestrator. It:
  1. logs the input;
  2. routes it to the event's owner sub-agent;
  3. runs independent agents in parallel;
  4. runs **b2b-qa** on every new draft, and sends the fixes back to the writer once;
  5. reports what waits for Karin.
- `duet/agents/*.md` → `.claude/agents/` hold the 10 team members. Each one follows its skill in `.claude/skills/<name>/`.
  - Tools are scoped per agent:
    - Gmail: drafts only, plus reading threads;
    - Calendar: read-only, with `timeZone: Asia/Jerusalem`, because her calendar is set to UTC;
    - WhisperAI: read-only.
  - No agent can send, reply, forward, delete, or create events.
- **New agents load at session start.** A session that has just created or changed them must restart before they are callable by name.

**Live test, 6 Nov 2026.** Fictional client "אורי (דמות לדוגמה)", in a scratch root, not committed.
